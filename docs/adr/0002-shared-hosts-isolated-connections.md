# 共享主机资料，按 MCP 连接隔离运行状态

用户在第二轮确认 Q7、Q8 和 Q9：主机档案、信任记录与默认记住的凭据跨客户端及重启保留；SSH 连接、各主机工作目录和临时凭据只属于当前 MCP 连接。这样 Codex CLI 与 Claude Code 可以使用同一主机库，同时不会相互改变工作目录，也无需将任务接管和持久后台任务系统纳入首版。

凭据默认记住，可显式选择 `remember: false`；登录凭据与 sudo 凭据分开管理，复用登录密码用于 sudo 必须明确指定。主机更新检测版本冲突；连接配置变化要求已有连接显式重连；删除阻止后续调用，不强行中断或重放已开始的命令。

本决定限定可观察行为；进程部署及文件布局见已确认的 [实现设计](../design.md)。
